# menubar-drawer

メニューバーを1アイコンだけにして、隠したものを引き出しから操作する macOS 常駐アプリ。

## 何をするか

- サードパーティのステータスアイテムをメニューバーの外へ押し出して、見た目を空にする
- メニューバーに残るのは **menubar-drawer のアイコン1つ** と OS 純正（時計・バッテリー・Wi-Fi・入力ソース・コントロールセンター）
- アイコンを押すと直下にガラスの引き出しが降り、隠れているアイテムがグリッドで並ぶ
- 引き出しの中のアイコンを押すと、そのアプリの**本物のメニュー**が開く

## 使い方

```sh
./scripts/build_app.sh     # dist/menubar-drawer.app を作る（Apple Development 証明書で署名）
open dist/menubar-drawer.app
```

初回はアクセシビリティ権限が必要（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。

- 引き出しアイコンを**右クリック**: 折りたたみの一時解除 / 権限設定 / 終了
- 引き出しの中のアイコンを**上へドラッグ**: メニューバーに出す（下記の制約あり）
- メニューバーに出ているアイコンを **⌘ドラッグで引き出しアイコンより左へ**: 折りたたむ

## 仕組み

macOS には他アプリのステータスアイテムを隠す API も、クリックする API もない。
Ice / Bartender / Hidden Bar と同じ方法を採る。

1. **押し出し** (`ItemPusher`) — 幅 4000pt のダミー `NSStatusItem` を1つ置き、その左のアイテムを画面外へ追い出す
2. **列挙** (`StatusItemScanner`) — 各アプリの AX 属性 `AXExtrasMenuBar` からステータスアイテムを取り、位置・名前・アイコンを得る
3. **操作** — 押し出しを一時的に畳んでアイテムを画面内へ戻し、実クリックを合成して押す

## 実測でわかったこと（推測でいじらないための記録）

| 事実 | 影響 |
|---|---|
| `NSStatusItem.length` の実効上限は約 **5002pt**。超える値を入れても getter は入れた値を返す | 10000 を入れると「縮めたのに実効幅が変わらない」バグになる。4000 に固定 |
| `AXUIElementPerformAction(AXPress)` はこのアプリから呼ぶと必ず **-25204** で失敗し、判明まで約1.5秒ブロック | AX 押下は使わず、実クリック合成 (`CGEvent`) で押す |
| 押し出しを畳んだ直後、AX は**移動途中の座標**を返す | 座標が止まるまで待ってから押す。決め打ち sleep は不可 |
| このマシンのノッチは **x=665〜850**（`NSScreen.auxiliaryTopRightArea` は 850 から） | ノッチ下に来たアイテムは掴めない。boringNotch がそのクリックを奪う |
| メニューバー左端（x≈40）に戻すとアプリメニュー領域に重なる | 引き戻し先はノッチより右にする |
| クリック合成はカーソルごと移動する | `CGWarpMouseCursorPosition` で元の位置に戻す |
| ステータスアイテムの並び順は **⌘ドラッグでしか変えられない**（公開 API なし） | 並べ替えは `ItemMover` が ⌘ドラッグを合成する |

## 既知の制約

- **メニューはメニューバー上のアイテム位置に開く**。引き出しの真下には出せない（メニューはステータスアイテムに紐づくため）
- **引き出しからの取り出し（上ドラッグ）は、対象がノッチの下に来ると失敗する**。押し出しを畳んだときの並び順は変えられないため、対象より左のアイテム数によっては掴める位置に出てこない
- 押し出し帯より右にあるアイテム（voicekey / What Watt? など）は折りたたまれない。帯の位置は ⌘ドラッグで調整する

## 構成

```
Sources/MenuBarDrawer/
  main.swift              起動
  AppDelegate.swift       アイコン・引き出しの開閉・押す/取り出す流れ
  StatusItemScanner.swift AX でステータスアイテムを列挙・クリック
  ItemPusher.swift        押し出し帯（幅可変のダミー NSStatusItem）
  ItemMover.swift         ⌘ドラッグ合成による並べ替え
  DrawerPanel.swift       ガラスの引き出し（NSPanel + SwiftUI）
spike/                    技術検証スクリプト（swift spike/xxx.swift で単体実行）
```
